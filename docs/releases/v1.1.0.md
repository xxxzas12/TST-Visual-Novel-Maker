# TSTVN v1.1.0

> ⭐ **Recommended version / เวอร์ชันแนะนำ** — the current main release of TSTVN.
> Previous public release: [v1.0.0](https://github.com/xxxzas12/TST-Visual-Novel-Maker/releases/tag/V1.0.0).

## 🇬🇧 English

TSTVN 1.1.0 is the first big update since v1.0.0. It brings a fully customizable **Game UI designer**
(textbox and choice styles, animations, a reusable Style Library), a flexible editor **workspace**,
autosave/recovery improvements, plugins, an in-game gallery and many fixes.

Versions 1.0.1–1.0.20 were development builds made on the way to this release. Their tags and detailed
reports are in the repository ([CHANGELOG](https://github.com/xxxzas12/TST-Visual-Novel-Maker/blob/main/CHANGELOG.md)),
but they have no separate installers. **1.1.0 contains all of them.**

### ✨ New features (since v1.0.0)

**Game UI designer (Themes)**
- Visual editor for the dialogue box, name box, choice buttons and menu bar: you select, drag, resize
  and align them on a live preview of the real game. It includes device previews (desktop, laptop,
  tablet, phones) and an automatic layout check.
- **Basic / Advanced** settings: Basic shows only the essentials; Advanced shows everything, with **?**
  help.
- **9 textbox styles with real shapes:** Classic VN, Modern, **Speech Bubble** (its tail points at the
  speaking character), Minimal, Fantasy, Sci-Fi, Horror, RPG, Retro. Point at a style to preview it,
  click to use it.
- Advanced textbox looks: glow, gradient, tiled texture, **your own frame image** (it fits any box size),
  text outline and shadow colour.
- **7 choice styles:** Classic, Modern, Minimal, RPG, Fantasy, Bubble, and **Image Button** (your own
  pictures for Normal / Hover / Pressed / Disabled). Also shapes and an icon in front of options.
- **Choice actions:** an option can also set or add to a variable, play a sound, animate a character or
  shake/flash the screen when chosen, all picked from menus with no code.
- **UI animations:**
  - the dialogue box appears and disappears with Fade, Slide, Pop, Scale, Bounce, Shake or Pulse;
  - text appears letter by letter, word by word, fading in or instantly;
  - choices appear one after another;
  - **▶ Preview** in the editor, and advanced timing (delay, direction, distance, size, rotation,
    opacity).
- **📚 Style Library:** save a textbox or choice style once and reuse it in any theme. Edit it once and
  every scene using it updates; **Edit only here** keeps a change local.
- Themes per project and per scene, and `.tsttheme` import/export.

**Editor**
- **Workspace:** resize panels by dragging, fold or hide them, put Properties on the left; presets
  Default / Writing / Scene Design / Art & Assets, plus your own saved layouts.
- **Application Settings**, separate from Project Settings:
  - language (English / ไทย);
  - appearance;
  - interface font;
  - application logo;
  - plugins;
  - autosave.
- **Autosave** on/off with an interval and a status-bar indicator. Crash recovery and Backups are kept.
- **Story Flow** shows broken connections (click one to fix it) and has an Open button on every scene.
- **Duplicate Project** from Project Settings or the Welcome screen.
- **Validation before export** now also checks variable types, conditions and choice actions.
- Per-project **game icon** (window, taskbar and Web favicon) and a custom **application logo**.

**Game features**
- In-game **Gallery** (CG, Characters, Music, Endings) with locked/unlocked items.
- Optional **Point & Click** scenes (clickable objects on the stage).
- Player text size and high-contrast settings; choice options can be shown greyed out when locked.

**Plugins**
- **Plugin Manager**: install from a `.tstplugin`/`.zip` file or a folder, enable/disable, remove. Plugins
  add game UI themes and action templates. They are content packs, so no code runs.

**Installer**
- A new two-step installer: **Install TSTVN** (Desktop shortcut and Start Menu icon options), then
  **✓ Installed successfully** with Launch. It installs for the current user, and upgrades keep
  shortcuts.

### 🛠️ Bug fixes
- Text inputs next to a live game preview lost focus after one character.
- An upgraded installation could lose its shortcuts or its uninstall entry.
- The in-game menu bar could be squeezed against the right edge, or wrap into several rows.
- Switching the editor language and creating a project at once could use the old language; overlapping
  settings writes could reset the language to English.
- Saving settings could fail with an "EPERM" error on Windows; it is now retried.
- Changing the autosave interval had no effect until the project was reopened. Autosave now counts from
  the first unsaved change.
- Several Game UI editor problems found while testing this release:
  - the Themes view could stay blank;
  - setting a texture raised an error;
  - several style picks merged into one undo step;
  - the Sci-Fi/Torn shapes cut off the name box;
  - ribbon/slanted name tags clipped letters.
- Editor preferences changed right after launch could be put back by settings that were still loading.

### ⚡ UX improvements
- The Game UI editor is easy by default (Basic) and powerful when needed (Advanced). Styles can be
  previewed before applying, and Reset returns to a preset.
- UI polish:
  - a compact getting-started checklist that folds out of the way and shows the next step;
  - one-line toolbars;
  - a marker on the active view in the sidebar;
  - consistent headers, spacing, button alignment and keyboard focus rings.
- Project Settings hold only game settings; editor settings moved to Application Settings.
- Projects and themes from v1.0.0 open unchanged. New settings default to the old look.

### ⚠️ Known limitations
- **Windows SmartScreen:** the installer is not code-signed, so Windows may show *"Windows protected your
  PC"*. Click **More info → Run anyway**.
- The editor runs on Windows 10/11 (x64). Games export to **Windows** and **Web** (the Web build also
  runs in phone browsers).
- The exported Windows game's `.exe` file icon in Explorer is still Electron's. The game window and
  taskbar do use the game icon.
- Plugins are content packs only (themes and action templates).
- The installer was tested on a real PC after a full uninstall, not on a fresh virtual machine.
- Full list: [KNOWN_ISSUES.md](https://github.com/xxxzas12/TST-Visual-Novel-Maker/blob/main/KNOWN_ISSUES.md).

### 📥 Install
1. Download **TSTVN-Setup-1.1.0.exe** below.
2. Run it and choose the shortcuts you want.
3. Click **Install**, then **Launch TSTVN**.

Upgrading from v1.0.0 works in place. Your projects are not touched.

## 🇹🇭 ภาษาไทย

TSTVN 1.1.0 เป็นอัปเดตใหญ่ครั้งแรกหลัง v1.0.0 มาพร้อม **ระบบออกแบบ UI ของเกม** ที่ปรับแต่งได้เต็มที่
(สไตล์กล่องข้อความ สไตล์ตัวเลือก แอนิเมชัน และคลังสไตล์ที่ใช้ซ้ำได้) **พื้นที่ทำงาน** ที่จัดได้ตามใจ
ระบบบันทึกอัตโนมัติที่ดีขึ้น ระบบปลั๊กอิน แกลเลอรีในเกม และแก้ไขข้อผิดพลาดอีกหลายจุด

เวอร์ชัน 1.0.1–1.0.20 เป็นรุ่นพัฒนาระหว่างทางก่อนถึงรุ่นนี้ มี tag และรายงานละเอียดอยู่ใน repository
([CHANGELOG](https://github.com/xxxzas12/TST-Visual-Novel-Maker/blob/main/CHANGELOG.md))
แต่ไม่มีไฟล์ติดตั้งแยก **1.1.0 รวมทุกอย่างจากรุ่นเหล่านั้นแล้ว**

### ✨ ฟีเจอร์ใหม่ (เทียบกับ v1.0.0)

**ระบบออกแบบ UI ของเกม (Themes)**
- ออกแบบกล่องบทสนทนา กล่องชื่อ ปุ่มตัวเลือก และแถบเมนูบนหน้าจอเกมจริงได้ เลือก ลาก ปรับขนาด และจัดแนว
  ได้ทันที มีตัวอย่างหน้าจอหลายอุปกรณ์ (PC แล็ปท็อป แท็บเล็ต มือถือ) และตรวจเลย์เอาต์ให้อัตโนมัติ
- โหมด **พื้นฐาน / ขั้นสูง**: พื้นฐานแสดงเฉพาะสิ่งที่จำเป็น ขั้นสูงแสดงทุกการตั้งค่า พร้อมคำอธิบาย **?**
- **สไตล์กล่องข้อความ 9 แบบที่รูปทรงต่างกันจริง:** VN คลาสสิก, โมเดิร์น, **กล่องคำพูด** (หางชี้ไปที่
  ตัวละครที่กำลังพูด), มินิมอล, แฟนตาซี, ไซไฟ, สยองขวัญ, RPG, เรโทร ชี้ค้างเพื่อดูตัวอย่าง คลิกเพื่อใช้
- ปรับแต่งกล่องข้อความขั้นสูง: แสงเรือง ไล่สี พื้นผิว **ภาพกรอบของคุณเอง** (ใช้ได้กับกล่องทุกขนาด)
  เส้นขอบตัวอักษร และสีเงา
- **สไตล์ปุ่มตัวเลือก 7 แบบ:** คลาสสิก, โมเดิร์น, มินิมอล, RPG, แฟนตาซี, บับเบิล และ **ปุ่มรูปภาพ**
  (ใช้ภาพของคุณเองสำหรับสถานะปกติ ชี้ กด และปิดใช้งาน) พร้อมรูปทรงและไอคอนหน้าตัวเลือก
- **การกระทำเมื่อเลือกตัวเลือก:** ตั้งค่าหรือบวกค่าตัวแปร เล่นเสียง ขยับตัวละคร หรือเขย่า/แฟลชจอได้
  เลือกจากเมนูทั้งหมด ไม่ต้องเขียนโค้ด
- **แอนิเมชันของ UI:**
  - กล่องบทสนทนาปรากฏและหายไปแบบเฟด สไลด์ เด้ง ขยาย กระเด้ง สั่น หรือพัลส์
  - ข้อความแสดงทีละตัวอักษร ทีละคำ ค่อย ๆ ปรากฏ หรือแสดงทันที
  - ตัวเลือกปรากฏทีละปุ่ม
  - กด **▶ ดูตัวอย่าง** ในโปรแกรมได้ และตั้งเวลาขั้นสูงได้ (หน่วงเวลา ทิศทาง ระยะ ขนาด การหมุน
    ความทึบ)
- **📚 คลังสไตล์:** บันทึกสไตล์กล่องข้อความหรือตัวเลือกไว้ครั้งเดียว ใช้ซ้ำได้ทุกธีม แก้ครั้งเดียว
  ทุกฉากที่ใช้จะอัปเดตตาม และมีปุ่ม **แก้เฉพาะที่นี่** สำหรับแก้แยก
- ธีมแยกระดับโปรเจกต์และระดับฉาก นำเข้า/ส่งออกไฟล์ `.tsttheme` ได้

**ตัวโปรแกรม**
- **พื้นที่ทำงาน:** ลากปรับขนาดแผง พับหรือซ่อนแผง ย้ายแผงคุณสมบัติไปซ้ายได้ มีชุดสำเร็จรูป ค่าเริ่มต้น /
  เขียนบท / ออกแบบฉาก / ภาพและไฟล์ และบันทึกเลย์เอาต์ของคุณเองได้
- **ตั้งค่าโปรแกรม** แยกจากตั้งค่าโปรเจกต์:
  - ภาษา (English / ไทย)
  - หน้าตา
  - ฟอนต์โปรแกรม
  - โลโก้โปรแกรม
  - ปลั๊กอิน
  - บันทึกอัตโนมัติ
- **บันทึกอัตโนมัติ** เปิด/ปิดได้ ตั้งช่วงเวลาได้ และมีตัวบอกสถานะที่แถบล่าง ระบบกู้คืนเมื่อโปรแกรมปิด
  ผิดปกติและระบบสำรองข้อมูลยังมีเหมือนเดิม
- **เส้นเรื่อง (Story Flow)** แสดงจุดเชื่อมต่อที่เสีย คลิกเพื่อไปแก้ได้ และมีปุ่มเปิดฉากบนทุกโหนด
- **ทำสำเนาโปรเจกต์** ได้จากหน้าตั้งค่าโปรเจกต์หรือหน้าแรก
- **ตรวจโปรเจกต์ก่อน Export** ครอบคลุมชนิดของตัวแปร เงื่อนไข และการกระทำของตัวเลือกด้วย
- **ไอคอนเกม** แยกต่อโปรเจกต์ (หน้าต่าง แถบงาน และ favicon ของเวอร์ชันเว็บ) และเปลี่ยน **โลโก้โปรแกรม** ได้

**ฟีเจอร์ในเกม**
- **แกลเลอรี** ในเกม (CG ตัวละคร เพลง ฉากจบ) มีระบบล็อก/ปลดล็อก
- ฉากแบบ **Point & Click** (คลิกวัตถุบนฉาก) ใช้ได้ถ้าต้องการ
- ผู้เล่นปรับขนาดตัวอักษรและโหมดคอนทราสต์สูงได้ และแสดงตัวเลือกที่ยังล็อกเป็นสีจางได้

**ปลั๊กอิน**
- **ตัวจัดการปลั๊กอิน:** ติดตั้งจากไฟล์ `.tstplugin`/`.zip` หรือโฟลเดอร์ เปิด/ปิด และลบได้ ปลั๊กอินเพิ่มธีม
  UI ของเกมและชุดแอ็กชันสำเร็จรูปได้ (เป็นชุดเนื้อหา ไม่มีการรันโค้ด)

**ตัวติดตั้ง**
- ตัวติดตั้งแบบใหม่ 2 ขั้นตอน: **ติดตั้ง TSTVN** (เลือกสร้างทางลัดบนเดสก์ท็อปและ Start Menu) แล้วไปหน้า
  **✓ ติดตั้งสำเร็จ** พร้อมปุ่มเปิดโปรแกรม ติดตั้งแบบรายผู้ใช้ และอัปเกรดแล้วทางลัดยังอยู่ครบ

### 🛠️ แก้ไขข้อผิดพลาด
- ช่องกรอกข้อความที่อยู่ข้างตัวอย่างเกมพิมพ์ได้ทีละตัวอักษร
- ติดตั้งทับเวอร์ชันเก่าแล้วทางลัดหรือรายการถอนการติดตั้งหาย
- แถบเมนูในเกมเบียดขอบขวา หรือขึ้นหลายแถว
- เปลี่ยนภาษาแล้วสร้างโปรเจกต์ทันทีได้ภาษาเดิม และการบันทึกตั้งค่าซ้อนกันทำให้ภาษากลับเป็นอังกฤษ
- บันทึกตั้งค่าล้มเหลวด้วย error "EPERM" บน Windows ตอนนี้จะลองใหม่ให้อัตโนมัติ
- เปลี่ยนช่วงเวลาบันทึกอัตโนมัติแล้วไม่มีผลจนกว่าจะเปิดโปรเจกต์ใหม่ และตอนนี้นับเวลาจากการแก้ไขครั้งแรก
  ที่ยังไม่บันทึก
- ปัญหาในหน้าออกแบบ UI ที่พบระหว่างทดสอบรุ่นนี้:
  - หน้าธีมว่างเปล่า
  - ตั้งค่าพื้นผิวแล้วขึ้น error
  - Undo ย้อนสไตล์ที่เลือกต่อกันได้ทีเดียวหมด
  - ทรงไซไฟ/ขอบขาดตัดกล่องชื่อหาย
  - ป้ายชื่อทรงริบบิ้น/เอียงตัดตัวอักษร
- การตั้งค่าที่เปลี่ยนทันทีหลังเปิดโปรแกรมอาจถูกค่าที่โหลดช้าเขียนทับ

### ⚡ ปรับปรุงการใช้งาน
- หน้าออกแบบ UI ใช้ง่ายตั้งแต่แรก (โหมดพื้นฐาน) และละเอียดได้เมื่อต้องการ (โหมดขั้นสูง) ดูตัวอย่างสไตล์
  ก่อนใช้ได้ และกด Reset กลับเป็นค่าสำเร็จรูปได้
- ขัดเกลา UI:
  - เช็กลิสต์เริ่มต้นใช้งานแบบกะทัดรัด พับเก็บได้ และบอกขั้นถัดไป
  - แถบเครื่องมือเรียงบรรทัดเดียว
  - แถบด้านข้างมีตัวบอกหน้าที่เปิดอยู่
  - หัวข้อ ระยะห่าง แนวปุ่ม และกรอบโฟกัสเมื่อใช้คีย์บอร์ดเป็นแบบเดียวกันทั้งโปรแกรม
- ตั้งค่าโปรเจกต์มีเฉพาะการตั้งค่าของเกม ส่วนการตั้งค่าโปรแกรมย้ายไปที่ตั้งค่าโปรแกรม
- โปรเจกต์และธีมจาก v1.0.0 เปิดได้เหมือนเดิม การตั้งค่าใหม่มีค่าเริ่มต้นที่หน้าตาเหมือนเดิม

### ⚠️ ข้อจำกัดที่ยังมีอยู่
- **Windows SmartScreen:** ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล Windows อาจขึ้น *"Windows protected your PC"*
  ให้กด **More info → Run anyway**
- ตัวโปรแกรมใช้บน Windows 10/11 (x64) Export เกมได้เป็น **Windows** และ **เว็บ** (เวอร์ชันเว็บเปิดบน
  เบราว์เซอร์มือถือได้)
- ไอคอนของไฟล์ `.exe` เกมที่ Export ใน Explorer ยังเป็นของ Electron แต่หน้าต่างเกมและแถบงานใช้ไอคอน
  เกมแล้ว
- ปลั๊กอินเป็นชุดเนื้อหาเท่านั้น (ธีมและชุดแอ็กชันสำเร็จรูป)
- ทดสอบตัวติดตั้งบนเครื่องจริงหลังถอนการติดตั้งจนหมด ยังไม่ได้ทดสอบบนเครื่องเสมือนที่ลงใหม่
- รายการทั้งหมด: [KNOWN_ISSUES.md](https://github.com/xxxzas12/TST-Visual-Novel-Maker/blob/main/KNOWN_ISSUES.md)
