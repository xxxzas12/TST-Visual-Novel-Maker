# TSTVN v1.0.5

## Feature
D. Application Logo (separate from each project's Game icon).

## What Changed
- **Application logo** (Application Settings → 🖼️ Application logo):
  - Choose Image… (PNG/JPG/ICO, max 10 MB, decoded by Electron to validate it), a preview of the image and
    of the TSTVN brand, and Reset.
  - Stored as `<userData>/branding/logo.<ext>` (`src/main/branding.ts`, `LogoStore`). It is shown as a data
    URL in the Welcome hero and the project top bar (`AppBrand`), and set as TSTVN's window/taskbar icon
    (`mainWindow.setIcon`; Reset restores the exe's icon).
- **Game icon** (Project Settings → Game, stored in `project.json` as `settings.gameIconAssetId`):
  - An image asset of the project. The Web export adds `<link rel="icon">`; the Windows export writes
    `icon` into `game-config.json` and the game shell uses it for its window.
  - Counted as a used asset (exported, validated). Asset usage, replace and delete handle it.
- The two never mix: the app logo lives in TSTVN's user data and is never copied into a game. The game
  icon lives in the project.

## Tests
- Unit `branding.test.ts` (3):
  - Logo set/get/reset; files that aren't usable images are rejected (wrong type, missing, not an image)
    and the previous state is kept.
  - The game icon is a used asset; the Web export writes the favicon link and the file; the Windows
    export writes `icon` in `game-config.json` and the file exists; deleting the asset clears the icon.
- E2E `branding.spec.ts`:
  - Choose a logo from the Welcome screen, check the preview and the brand, restart (persists), and
    check the logo in the project top bar.
  - Import an image, set it as the Game icon, export Web, and check `index.html` has the icon and no
    logo file is in the game. Then Reset.
- Manual: a Win32 screenshot of the real TSTVN window showed the custom logo as the title-bar icon.
- Gate: installer build OK, lint 0, unit 78/78, E2E 13/13 (incl. packaged app).

## UI Changes
- New "Application logo" category in Application Settings; logo next to "TSTVN" on the Welcome screen and
  the top bar when set.
- New "Game icon" field in Project Settings.

## Compatibility
New optional fields only (`settings.gameIconAssetId`); older projects open unchanged.

## Known Issues
- The exported Windows **.exe file** icon in Explorer is still Electron's: changing an exe's embedded
  icon needs a resource editor, which isn't bundled. The game window and taskbar use the game icon.
