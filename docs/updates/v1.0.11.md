# TSTVN v1.0.11

## Feature
K. Scene Flow (existing — gaps fixed) + Duplicate Project (audit item 7, missing).

## What Changed
- **Story Flow already did** (kept, not duplicated): scenes and branches, choice connections with
  labels, condition edges, drag-to-connect, delete arrows, double-click to open, list view.
- **Added to the same view and `shared/flow.ts`:**
  - `brokenLinks(project)` finds Jump to Scene / Change Scene / Jump / Check Variable / Conditional
    (if true / otherwise) / Choice option / Point & Click object targets that point to a missing scene,
    label or action. Disabled actions are ignored.
  - Header button "⚠ N broken connection(s)" opens a list. Clicking an entry opens that scene with the
    broken action selected, ready to fix.
  - Scene nodes show a red "⚠ n" badge, and an explicit **Open** button (single click; double-click
    still works).
- **Duplicate Project** (`main/projectStore.ts` `duplicateProject`, IPC `project:duplicate`):
  - Copies the saved project folder (assets, fonts, thumbnails) next to the original under a unique name,
    with a new id and name. The game title follows the name if it was the same.
  - The original's backups and unsaved-work recovery file are not copied.
  - From Project Settings it saves unsaved changes first, then opens the copy. The Welcome screen has
    ⧉ on each recent project.
