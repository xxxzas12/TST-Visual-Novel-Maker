# TSTVN v1.0.16

## Feature
UI/UX Phase 5: Game UI animation presets. The dialogue box (appear and disappear), how the text
appears, the "continue" mark, and choice buttons (with one-after-another) can each be animated, with
▶ Preview in the editor.

## Inspection (before changing anything)
- **Already present (kept):**
  - one theme setting "Dialogue box animation" (Fade / Slide up / None, fixed 0.25 s);
  - typewriter text with a speed;
  - choice hover/press feedback;
  - character enter/exit/emphasis animations and screen effects (story actions, untouched).
- **Missing:**
  - an exit animation;
  - other text reveals;
  - choice entrance and stagger;
  - indicator styles;
  - durations and easing;
  - any preview of an animation in the editor.

## What Changed
- **`src/shared/uianim.ts`**:
  - `AnimSpec` (kind, direction, duration, delay, easing, distance, scale, rotation, start opacity).
  - Presets:
    - Entrance: None, Fade In, Slide Up/Down/from Right/from Left, Pop, Scale, Bounce, Shake, Pulse.
    - Exit: None, Fade Out, Slide Down/Up/Left/Right, Shrink.
    - Each fills in a sensible duration, easing and distance, so a beginner never has to understand
      easing curves.
  - Easings have friendly names (Ease Out "smooth stop", Overshoot, Springy…).
  - `animFrames` builds the keyframes used by both the editor and the game. Exits are mirrored
    entrances, and distances scale with the screen.
- **Theme:**
  - New `anim` {dialogIn, dialogOut, text, choicesIn, choiceStagger, indicator}.
  - Older themes, `.tsttheme` files and the 9 theme presets get theirs from the old `animation`
    setting (fade / slide / none), so they look exactly as before. The old setting is kept in step
    for older TSTVN versions.
- **Runtime:**
  - The dialogue box plays its entrance when it appears and its exit before choices without a
    question or before point & click.
  - Text appears typewriter (as before), word by word (never cut inside a word), fading in, or
    instantly. Clicking still finishes it at once.
  - Choice buttons play their entrance, optionally one after another.
  - The "continue" mark can bounce, pulse, blink or stay still.
  - Skip mode skips the animations.
- **Editor:**
  - Dialogue Box gets an "Animation" section: Appear [preset ▾] ▶ + Duration + Easing; Disappear
    (same); Text appears [▾] ▶; "Continue" mark [▾].
  - Choice Buttons get Appear [preset ▾] ▶ + Duration + Easing, and "One after another".
  - The theme overview's "Dialogue box animation" became the same control (no duplicate setting).
  - ▶ plays the animation in the live canvas (new `tstvn:replay` message to the preview).

## Compatibility
- Additive. Old projects keep their dialogue box animation; choices still appear without animation and
  the text stays typewriter until changed.
- Older TSTVN versions read the kept `animation` setting.
