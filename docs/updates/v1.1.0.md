# TSTVN v1.1.0

The first release on the new version line. The app is identical to v1.0.20 (the verified release
candidate): only the version number and the release documents change. The minor version marks the
UI/UX and Game UI customization work of v1.0.12–v1.0.20.

## Added
- No new features compared with v1.0.20. Since 1.0.11 (all already released as 1.0.12–1.0.20):
  - editor workspace (resizable, foldable, swappable panels; presets; saved layouts);
  - textbox styles with real shapes, Basic/Advanced settings, advanced textbox looks;
  - choice styles, button pictures, "when chosen" actions;
  - Game UI animations with presets, preview and advanced timing;
  - Style Library (reusable textbox and choice styles);
  - UI polish pass.

## Changed
- Version 1.0.20 → **1.1.0** (`package.json`, `package-lock.json`). The installer is now
  `TSTVN-Setup-1.1.0.exe`, and the About page and Windows file version show 1.1.0.
- `RELEASE_NOTES.md`, `KNOWN_ISSUES.md`, `CHANGELOG.md` and `docs/VERSION_HISTORY.md` refer to 1.1.0.
  VERSION_HISTORY now lists 1.0.20's commit (eeb6c2b).
