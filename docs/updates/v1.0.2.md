# TSTVN v1.0.2

## Feature
A. UX / Settings — Application Settings separated from Project Settings.

## What Changed
- New **Application Settings** window with categories, available before any project is open:
  - **General:** editor language, appearance (Dark/Light/Follow Windows), getting-started checklist.
  - **Interface & fonts:** interface font and interface size (program font size; this is the UI scale),
    with Dark/Light previews and Apply/Cancel/Reset.
  - **Autosave & recovery:** autosave interval.
  - **About:** version and default project folder.
- It opens from the Welcome screen (⚙ Settings, next to the language) and from the ⚙ button in the
  project top bar. Keyboard shortcuts are paused while it is open.
- The **Project Settings** page (nav "Project") keeps only settings stored in the project: game name,
  title, author, start scene, resolution, text speed, game language, window mode, title screen, game
  font, project files. It links to Application Settings.
- The font settings component was split into `UiFontSettings` (app) and `GameFontSettings` (project).
  The game-font preview now restarts only when what it shows changes, not on every project edit.
