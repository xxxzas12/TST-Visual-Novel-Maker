# TSTVN v1.0.15

## Feature
UI/UX Phase 4: Choice button presets, shapes, icon, your own button pictures per state, and choice
behaviour ("when chosen" actions).

## Inspection (before changing anything)
- **Already present (kept):**
  - Choice buttons with Normal / Hover / Pressed / Disabled colours (background, text, border, opacity).
  - Hover animations (grow/lift/glow/slide), press animations (shrink/sink) and their speed.
  - Position/anchor, width, minimum width/height, padding and spacing.
  - Font, size, line/letter spacing, alignment.
  - Border width, radius, shadow, one background image, blur.
  - From v1.0.14: glow, texture, frame image.
  - Options already had: a target (next / scene / label / action), an "only show if" condition, and
    "show greyed out when locked".
- **Missing:**
  - choice presets;
  - shapes other than a rounded rectangle;
  - an icon;
  - a different picture per state (Image Button);
  - any action other than "go to" when an option is chosen.

## What Changed
- **Data** (additive):
  - `choice.shape`: `box | pill | bubble | banner | underline | cut | tag`.
  - `choice.icon`: up to 4 characters.
  - `choice.preset`.
  - `states.*.image`: a picture per state.
  - `ChoiceOption.effects`: `setVariable | addVariable (negative = subtract) | playSound | animateCharacter | screenEffect`.
- **`src/shared/choicestyle.ts`**, 7 presets:
  - **Classic**: parchment buttons with a brown frame.
  - **Modern**: glass, blue on hover.
  - **Minimal**: text with an underline.
  - **RPG**: a menu on the right with ▶.
  - **Fantasy**: purple/gold notched banners with ✦ and glow.
  - **Bubble**: chat bubbles with a tail.
  - **Image Button**: your own pictures; colours only as a fallback. Pictures already chosen are kept
    when you switch to it.

  "Custom" is any preset you then change (Reset brings back the preset). Saved reusable custom styles
  come in Phase 7.
- **Runtime:**
  - Shapes through `data-c-shape`.
  - Per-state pictures through CSS variables. An empty state falls back: Pressed → Hover → Normal,
    and Disabled → Normal.
  - The icon is drawn in front of the label from the theme, so live edits show at once.
  - High contrast removes the pictures.
  - Option text now sits in a `.tvn-choice-label` span; the button's text content is unchanged.
- **Engine:** after an option is picked, its effects run in order before the story continues:
  - variables change (with type conversion; add/subtract for numbers);
  - the sound plays;
  - the character animation and the screen effect are awaited.
- **Validation:**
  - missing variable to change;
  - adding to a non-number variable;
  - a value that doesn't fit the variable type;
  - missing sound file (error) or no sound chosen (warning);
  - no character to animate (warning).

  Sounds used by options are shipped with exported games and update when assets are replaced or deleted.
- **Editor:**
  - Choice Buttons gets a "Choice style" gallery with hover preview, click to apply (a preset theme is
    copied), and ⟲ Reset.
  - **Basic** shows anchor, width, spacing, per-state background and text colour, font and size. The
    Image Button picture field also shows in Basic when that preset is used.
  - **Advanced** adds X/Y, sizes, padding, "Shape & icon" (shape list, icon field with ▶ ◆ ✦ ♥ ★ ➤
    quick buttons), per-state opacity, border and picture, hover/press feedback and button style.
  - Scene editor → Choice → each option has "＋ When chosen, also…" (Set a variable / Add to a number
    variable / Play a sound / Animate a character / Screen effect), built from menus with no code.

- Unit `choices.test.ts` (8):
  - 7 distinct presets.
  - Applying changes only the choices, and Image Button keeps pictures.
  - CSS for pictures and the icon.
  - Pictures are used assets and are cleared on delete.
  - Old themes load as a plain box with no icon, and theme presets are unchanged.
  - Effects run in order (set, add, subtract, sound, animate, shake) before the next line.
  - The other option does nothing extra.
  - Validation catches 5 kinds of broken effects.

  - Hover preview leaves the project unchanged.
  - Each of the 7 presets gives its shape (screenshots reviewed), and only one copy of the preset
    theme is made.
  - Image Button: pick Normal and Hover pictures, visible in the canvas.
  - Advanced: pill shape, ♥ icon, undo/redo.
  - Scene: the "Take the key" option gets "Add 5" and "Screen shake"; in the game the button shows
    the picture and the ♥, and choosing it shows "Score 5".
  - The effects are saved in `project.json`.
- Gate: see the commit report.

## UI Changes
- Choice style gallery, Shape & icon section, per-state Button picture, "When chosen" in choice options.

## Compatibility
- Additive only. Existing choices keep their look (box shape, no icon, no pictures) and behaviour (no
  effects).
- Older TSTVN versions ignore the new fields.

## Known Issues
- "Animate a character" only shows if the character is on stage at that moment (same as the Animate
  Character action).
- Gradients are not offered for choice buttons, because they would hide the per-state colours.
