# TSTVN v1.0.13

## Feature
UI/UX Phase 2: Textbox style presets with genuinely different shapes, plus preview-before-apply in
the live canvas.

## Inspection (before changing anything)
- **Already present (kept):**
  - 9 whole-theme presets (Modern, Minimal, Classic, Dark, Fantasy, Soft, RPG, Romance, Horror).
  - The live Game UI canvas: the real runtime in design mode. Style edits reach it without a restart.
  - Device previews (desktop, laptop, tablet, phone, both orientations).
  - Per-scene theme override, and `.tsttheme` import/export.
- **Gap:** every preset was the same rectangle with other colours, border and radius. There was no
  shape concept for the dialogue box or name box, and no way to restyle only the textbox while keeping
  the theme's choices and menus.

## What Changed
- **Data** (`types.ts`, additive):
  - `dialog.frame`: `box | bubble | band | ornate | tech | torn | window | pixel`.
  - `dialog.preset`: the last textbox preset applied.
  - `nameBox.shape`: `box | tab | ribbon | plain | slant | pixel`.
  - `normalizeTheme` fills missing values with `box` and repairs unknown ones.
- **`src/shared/textbox.ts`**, 9 textbox presets. Each sets the dialogue box and name box only and
  keeps the theme's text speed. Choices and menus are untouched.

  | Preset | Box | Name box |
  |---|---|---|
  | Classic VN | framed serif box | tab joined to the box |
  | Modern | frosted rounded glass | coloured pill |
  | Speech Bubble | white comic bubble, tail points at the speaking character | name only |
  | Minimal | no box, a shadow band fading into the scene | name only |
  | Fantasy | double gold border, corner gems | ribbon banner |
  | Sci-Fi | cut corners, thick accent edge, scan lines, glow | slanted tag |
  | Horror | torn ragged edges, red inner glow | red name only |
  | RPG | game window with double frame and sheen | its own name window |
  | Retro | pixel-art stepped border, typewriter font, step-blinking ▼ | pixel tag |
- **Runtime** (`player.ts`, `runtime.css`):
  - Frames and shapes are CSS driven by `data-d-frame` and `data-n-shape`. They use the theme's own
    colour, border and text variables, so a preset can still be recoloured and high-contrast still
    works.
  - Speech bubble: the tail is placed on the side facing the stage and aims at the speaking character's
    position on stage, or near the left edge when they are off stage. There is no tail for narration
    or for a choice question.
  - The tail updates on every layout (resize, theme change).
- **Editor** (`ThemesView.tsx`, `themes/TextboxPresets.tsx`, `themes/ThemeProps.tsx`):
  - With the Dialogue Box or Name Box selected, a "Textbox style" gallery of 9 cards appears. Each card
    has a small drawing of its shape.
  - **Pointing at (or keyboard-focusing) a card previews it in the canvas without changing the project.**
    Clicking applies it.
  - Applying to a read-only preset theme creates a custom copy automatically (the preset stays
    unchanged) and uses it where the preset was used.
  - "Shape" dropdowns for the dialogue box and name box allow changing the shape by hand.

## Bug Fixes (found while testing this version)
- Clicking several textbox presets in a row merged into one undo step (shared undo key). Each pick is
  now its own step.
- The Sci-Fi and Torn shapes cut off a name box placed on top of the box. The shape is now cut on
  background layers only.
- Ribbon and slanted name tags clipped the first and last letters when the padding was 0. They now keep
  a minimum side padding.

## UI Changes
- Game UI editor: a "Textbox style" gallery (Dialogue Box / Name Box), and "Shape" dropdowns.

## Compatibility
- Existing projects and `.tsttheme` files load unchanged as a plain box, so they look exactly as before.
- The 9 whole-theme presets were deliberately not changed, so games using them don't change look.
- Older TSTVN versions opening a newer project ignore the new fields and show a plain box.

## Known Issues
- The bubble tail aims at the character's stage position when the line starts. If the character moves
  during the line, the tail follows on the next line or layout.
- The torn edge uses fixed pixel offsets, so it looks slightly finer on very large screens.
