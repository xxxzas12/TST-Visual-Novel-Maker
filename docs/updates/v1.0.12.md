# TSTVN v1.0.12

## Feature
UI/UX Phase 1 — Editor workspace: resizable, foldable, hideable and swappable panels, workspace presets,
saved workspaces, and a remembered layout.

## Inspection (before changing anything)
- The editor had a fixed layout: top bar, left navigation, and a Scene editor with a fixed grid
  (`17rem | 1fr | 22rem`). The stage height was hard-wired to 38% of the window.
- There was no panel or layout state anywhere. The left panel's tab (Scenes / Assets / Cast) was
  local state, so it was forgotten on every view change.
- Application Settings (`settings.json` in userData, `app:getSettings` / `app:setSettings`) already stores
  per-computer editor preferences, so the layout is saved there. There is no new storage and no
  project data change.

## What Changed
- **`src/shared/workspace.ts`**:
  - Layout model: left panel width, inspector width, stage height share, per-panel state
    `open | collapsed | hidden`, swap sides, compact sidebar, and the left tab.
  - Four presets: **Default**, **Writing** (stage folded, compact sidebar, wider properties),
    **Scene Design** (large stage, Cast tab) and **Art / Assets** (wide Assets panel).
  - `normalizeLayout` clamps damaged or old settings. `isUnchanged` shows "*" when the layout was
    changed from its workspace.
- **Scene editor** (`ScenesView.tsx`, `Stage.tsx`):
  - Dividers between panels (`components/Splitter.tsx`). Drag to resize, arrow keys when focused
    (Shift = 50px), double-click to reset to the workspace size.
  - The stage has its own horizontal divider.
  - Fold buttons (« » on the panels, "▴ Fold" on the stage) turn a panel into a thin labelled bar
    that reopens it in one click.
  - The inspector got a small "Properties" header holding the fold button.
- **Top bar "🪟 Workspace" menu** (`components/WorkspaceMenu.tsx`):
  - presets with descriptions;
  - "My workspaces" (save current layout, delete);
  - Reset layout;
  - show/hide each panel;
  - "Properties on the left" (swap sides);
  - "Compact sidebar (icons only)".
  - Keyboard: ↑/↓ and Esc.
- The layout is saved 0.4 s after the last change (dragging doesn't write on every pixel) and
  restored at startup.
- The compact sidebar keeps accessible names (`aria-label`) and tooltips.

## Not implemented (by design or deferred)
- **Undocking panels into separate windows**: it would need several synchronized Electron windows
  sharing undo/redo and selection state, a large risk for a small gain. Panels can be resized, folded,
  hidden and moved to the other side instead.
- Free drag-and-drop repositioning of every panel: limited to swapping the two side panels, which
  keeps the layout simple.

## Bug Fixes (found by the full E2E run of this version, fixed before the commit)
- Remembering the left tab made the Scenes list stay on Assets after visiting another view (acceptance and
  features tests could not find scenes). The tab now starts on the workspace's tab; clicking tabs is not saved.
- A `position: relative` added to the properties panel made the absolutely positioned list rows of the Game
  UI editor cover the "Add button" control. Reverted (the panel header is sticky instead).

## Tests
- Unit `workspace.test.ts` (4):
  - damaged settings fall back or clamp;
  - the 4 presets differ and are returned as copies;
  - modified detection;
  - saved workspaces are read and broken entries dropped.
- E2E `workspace.spec.ts` (own userData), all with real mouse drags:
  - Resize the left panel, inspector and stage, plus a keyboard resize.
  - Fold and reopen the inspector and stage.
  - Hide the left panel from the menu and swap sides.
  - Writing preset: stage folded, compact sidebar, and typing in the text field still works.
  - Art preset: Assets tab, 440px.
  - Save "My Art", switch away and back.
  - Restart the app: the layout and the saved workspace are restored, then delete the workspace.
- Gate: installer build OK, lint 0, unit 104/104. Full E2E: 15/20 on the first run → the 5 failures were the
  two regressions above (the autosave test timed out once and passed on rerun). After the fixes the 5 failed
  specs (acceptance, features ×6, uitheme ×2, autosave, workspace) were rerun: all passed.

## UI Changes
- Top bar: "🪟 Default ▾" workspace menu.
- Scene editor: dividers, fold buttons and bars, "Properties" header.
- Sidebar can be icon-only.

## Compatibility
No project data changes. Older `settings.json` without a layout opens with the Default layout, which
looks the same as before.

## Known Issues
- The workspace applies to the Scene editor (where the panels are). Other views keep their own fixed
  layouts.
