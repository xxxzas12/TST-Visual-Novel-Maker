# TSTVN v1.0.9

## Feature
I. Validation before Export (gaps) — and H. Variables / Flags (already existed; verified).

## What Changed
- **H — already exists**, so nothing was added and nothing duplicated.
  - Boolean/Number/String variables, Set/Add/Subtract, Check Variable, Conditional Branch (if/else,
    all/any), choice conditions, `{Variable}` in dialogue, and conditional jumps to scenes.
  - A new test plays the requested examples end to end: `affection >= 20` → Good Ending,
    `has_key == true` on a choice, `{hero} has {affection} affection.`
- **I — what already existed** (audit, corrected):
  - Errors block export, and the export re-checks every file.
  - Issues are clickable and jump to the scene/action.
  - Missing files offer Locate / Replace / Remove.
  - Already checked: missing assets/files, broken scene links (scene/label/action), invalid choices (no
    options/text), missing destinations, missing variables, and missing fonts.
- **I — added** (`shared/validate.ts`: `valueFits`, `conditionProblem`):
  - Errors:
    - A True/False variable compared with anything other than "equals"/"is not".
    - A condition comparing a variable with a value of another type. This applies in choices,
      Conditional Branch, Check Variable and Point & Click.
    - Set Variable, and Point & Click "set variable", with a value that doesn't fit the type.
    - Add/Subtract Value on a non-number variable.
  - Warning: `{Name}` in dialogue/question/hint/message text that isn't a variable (players would see the
    braces).
  - Values typed as text that clearly fit (`"true"`, `"20"`) are accepted, so existing projects don't
    get false errors. All built-in templates validate clean in English and Thai.
