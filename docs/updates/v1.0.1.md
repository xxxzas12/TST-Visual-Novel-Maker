# TSTVN v1.0.1

## Feature
Game UI / Theme Editor (+ feature audit).

## What Changed
- Themes became a full game-UI description (dialogue box, name box, choices with four states, menu
  bar buttons, menus, fonts, animations, accessibility). Sizes are design px on a 1920×1080 canvas or
  %/vw/vh, and the runtime lays them out on any screen (`shared/uilayout.ts`).
- The Themes view is a visual editor that runs the real runtime in design mode, with device previews,
  a multi-device layout check (`shared/uicheck.ts`), presets, custom presets, `.tsttheme` export/import
  and scene overrides.
- The runtime reads every UI style from the theme; scene overrides switch theme when a scene starts.
- `docs/audit-v1.0.0.md` records the audit of existing systems that drives the next versions.

## Bug Fixes
- `app:setSettings` read-modify-write was not serialized; overlapping calls reset the language.
- Menu bar wrapped into several rows on wide screens (measured while shrink-wrapped).

## Tests
- `npm run lint` 0 problems, `npm run typecheck` 0 errors.
- `npm test` 75/75, `npm run test:e2e` 10/10 (incl. two new Game UI tests).
- `npm run dist` OK; packaged test passed against the installed copy.

## UI Changes
- Themes view redesigned as "Game UI & Themes" (canvas, devices, properties panel, layout check).
- 🎨 scene theme menu in the Scenes view; "show greyed out" option for choice conditions.
- In-game Settings: Text size, High contrast.

## Compatibility
Existing projects open unchanged: version-1 themes and dialogue font sizes are migrated on load
(`settings.uiVersion = 2`). Exported games are rebuilt with the new runtime when exported again.

## Known Issues
- Settings text inputs lose focus after one character (found by the audit; fixed in v1.0.3).
