# TSTVN v1.0.10

## Feature
J. Autosave (existing system — gaps fixed, kept separate from Backup).

## What Changed
- **Already existed:**
  - A real save every N minutes.
  - Crash-recovery snapshots every 10 s with Recover/Discard on reopen (E2E tested since v1.0.0).
  - Backups (a separate system).
- **New rules module** `src/shared/autosave.ts` (pure, tested): `autosaveConfig` (on/off + 1–60
  minutes; old "0 minutes" = off is migrated), `autosaveDue` and `autosaveIn`.
- **Project store:**
  - Tracks `dirtySince` (time of the first unsaved change) and `savedByAutosave`.
  - Autosave happens N minutes after the first unsaved change.
- **Scheduler** (`Shell.useAutosave`):
  - Reads the live setting from the UI store on every tick, so interval and on/off changes apply
    immediately (previously read once when the project opened).
  - Never runs two saves at once. Recovery snapshots are unchanged.
- **Application Settings → Autosave & recovery:**
  - "Autosave the project" checkbox and the interval (minutes after the first unsaved change).
  - Text explaining that crash recovery is always on and separate from Backups.
- **Status bar:**
  - "✓ Autosaved hh:mm" vs "✓ Saved hh:mm".
  - A clickable autosave indicator: "Autosave in m:ss", "Autosave every N min" or "Autosave off".

## Files Changed
- Added: `src/shared/autosave.ts`, `tests/autosave.test.ts`, `e2e/autosave.spec.ts`.

## Bug Fixes
- Autosave interval/on-off changes ignored until the project was reopened.
- Autosave timer counted from opening the project instead of from the first change.
- The autosave checkbox waited for the settings write before changing (now immediate).

## Tests
- Unit `autosave.test.ts` (2): settings migration and clamping; due time / countdown; off; nothing unsaved.
- E2E `autosave.spec.ts` (real time, ~1 min):
  - With 2 minutes, an edit shows "Autosave in 1:5x". Switching to 1 minute while the project is open
    makes the countdown follow.
  - After about 60 s the status shows "Autosaved" and `project.json` on disk contains the edit.
  - A manual save shows "Saved". With autosave off the indicator shows "Autosave off" and the edit
    stays unsaved.
- Existing crash-recovery E2E (Recover/Discard) still passes.
- Gate: installer build OK, lint 0, unit 98/98, E2E 17/17 (incl. packaged app).

## UI Changes
- Autosave section in Application Settings; autosave indicator in the status bar.

## Compatibility
Old `autosaveMinutes` values keep working (0 = off). No project data change.
