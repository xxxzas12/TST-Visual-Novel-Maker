# TSTVN v1.0.14

## Feature
UI/UX Phase 3: Advanced textbox customization and the **Basic / Advanced** split in the Game UI editor.

## Inspection (before changing anything)
- **Already present (kept, now grouped under Advanced):**
  - border colour and width, corner radius, shadow (size/offset/colour/opacity), background blur;
  - background image with fit, padding;
  - text alignment, line height, letter spacing, bold, text shadow;
  - name box placement, alignment, offsets and minimum size.
- **Missing:**
  - glow;
  - gradient;
  - texture;
  - a custom frame image that fits any box size;
  - text outline and text shadow colour;
  - a beginner view (every setting was always shown);
  - help for unfamiliar settings;
  - a reset for the textbox look.

## What Changed
- **Data** (additive, all off by default, so themes look exactly as before):
  - `UiSurface.glow` {size, color, opacity}
  - `UiSurface.gradient` {enabled, color, angle}
  - `UiSurface.texture` (asset)
  - `UiSurface.frameImage` (asset) + `frameSlice` (%) + `frameWidth`
  - `UiText.shadowColor`, `outline`, `outlineColor`
- **Runtime:**
  - The glow is added to the box shadow.
  - The gradient is a background layer.
  - The texture is tiled on the image layer.
  - The frame image is a 9-slice `border-image` with the centre filled: the corners keep their size and
    the edges stretch, so `my_dialogue_frame.png` fits any box size.
  - Text outline uses `-webkit-text-stroke` with the stroke painted under the fill.
  - All sizes scale with the screen.
  - Works with every textbox shape (bubble, tech, torn, window…).
  - High-contrast mode switches all of these off.
- **Asset bookkeeping:** textures and frame images count as used assets. Replacing or deleting an asset
  updates them, and `.tsttheme` export/import carries them (`mapThemeImages` / `themeAssetIds`).
- **Editor:**
  - "Basic | Advanced" switch at the top of the properties panel. **Basic is the default.** The
    choice is remembered in Application Settings.
  - Basic shows anchor, width/height, background colour, opacity, font, size and text colour, plus
    name box show/placement/alignment.
  - Advanced shows everything, including the new settings.
  - Basic shows a hint that more settings are in Advanced.
  - "?" help marks (hover or keyboard focus, read by screen readers) on texture, frame image, corner
    size, glow, blur, text outline and fallback fonts.
  - "⟲ Reset to ‹preset›" re-applies the textbox preset, undoing hand changes to the dialogue and name
    box. Undo/redo work for every setting.

## Bug Fixes (found while testing this version)
- Listing a theme's images wrote every image slot back to itself. On the editor's frozen state this
  threw "Cannot assign to read only property" as soon as a texture was set. Listing is now read-only,
  and replacing writes only changed slots.

## UI Changes
- Basic / Advanced switch; new Advanced settings; ? help marks; Reset button under Textbox style.

## Compatibility
- Additive only: old projects and `.tsttheme` files load with the new settings switched off.
- Nothing is removed or renamed. The existing settings are all still there, under Advanced.

## Known Issues
- Texture opacity follows the box opacity (there is no separate texture opacity).
- Frame images ignore the corner radius (CSS border images are always rectangular). Round frames come
  from the picture itself.
