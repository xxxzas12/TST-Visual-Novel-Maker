# TSTVN v1.0.7

## Feature
F. Gallery system for games (CG / Character / Music / Ending galleries with locked/unlocked state).

## What Changed
- **Items come from the story** (`src/shared/gallery.ts`, `galleryItems`), once each in story order:
  - CG = Show CG assets; Characters = characters added on stage; Music = Play/Change BGM assets and the
    title music; Endings = End Game actions (title = message, plus scene name). Disabled actions are
    ignored.
- **Unlock rules** per item key: `GalleryUnlock = { mode: 'seen' } | { mode: 'always' }`.
  - Saved in `settings.gallery.unlock` (default "seen").
  - A union, so later rules (e.g. `{ mode: 'condition', condition }`) can be added without migrating data.
- **Runtime** (`player.ts`):
  - Records what is seen while rendering (CG on screen, characters and their expressions on stage, BGM
    playing) and when an ending is reached. The engine now passes the End Game action id to
    `host.end`.
  - Unlocks are stored per game in local storage (`unlocks`), separate from save slots.
  - A **Gallery** button on the title screen (only when enabled) opens tabs with "unlocked/total" counts.
    Locked items show 🔒 ???. A CG opens a full-screen viewer; a character shows its seen expressions;
    music plays/pauses (title music returns when leaving); endings are listed with their scene.
  - The layout adapts to phones (compact grid). Thai runtime strings were added.
- **Editor** (`GallerySettings.tsx`, Project Settings):
  - "Game Gallery" card: enable, section checkboxes with counts (CG / Character / Music / Ending
    Gallery), and per-item "Unlocks when seen / Always unlocked".
- No editor-side gallery was added (the editor already has its asset gallery).

## Compatibility
Optional new setting (`settings.gallery`); projects without it have no gallery. Existing saves are
unaffected (unlocks use their own storage key).

## Known Issues
- Only "seen" and "always" rules exist today (as asked: more conditions later).
- The Character gallery counts characters that appear on stage (Add Character), not speakers who only
  talk.
